# Imran Khan — Portfolio

Static portfolio site built with HTML, CSS and JavaScript. Open `index.html` in a browser to view it.

## Included

- `index.html`, `styles.css`, and `script.js`
- `imran-portrait.jpeg` — the portrait provided with the portfolio

The site presents professional experience, capabilities, selected work areas, education, contact information and LinkedIn. It intentionally does not publish the source CV or private personal details from it.

## Publish

This folder can be deployed as a static site with GitHub Pages, Netlify, or Lovable. Keep `index.html`, `styles.css`, `script.js`, and `imran-portrait.jpeg` together so the portrait loads correctly.
